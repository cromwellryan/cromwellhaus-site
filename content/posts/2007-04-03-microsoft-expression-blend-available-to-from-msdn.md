One of the cool tools we had a chance to use while up at the WPF Bootcamp in Redmond was [Expression Blend](http://www.microsoft.com/expression/products/overview.aspx?key=blend).  While there I became pretty engrossed in the ease with which you could create fairly cool animations without an intimate knowledge of Xaml.  This made it all that harder to leave seeing as we had the latest bits at the time (the [Release Candidate](http://www.microsoft.com/products/expression/en/expression-blend/try.mspx) is available as a 30 trial).  Fortunately, or gratefully?, Microsoft has [decided](http://blogs.msdn.com/somasegar/archive/2007/04/03/listening-to-your-feedback-expression-and-msdn.aspx) to make it available on [MSDN](http://msdn2.microsoft.com/subscriptions).  That means me!

I will say though, while reading [Charles Petzold](http://www.charlespetzold.com/blog/blog.xml)'s book [![](http://images.amazon.com/images/P/0735619573.01._AA_SCTZZZZZZZ_.jpg)](http://www.amazon.com/exec/obidos/redirect?path=ASIN/0735619573&link_code=as2&camp=1789&tag=ryancrom-20&creative=9325 "Application = Code + Markup")[Application = Code + Markup](http://www.amazon.com/exec/obidos/redirect?path=ASIN/0735619573&link_code=as2&camp=1789&tag=ryancrom-20&creative=9325) which starts with Code and then moves to Xaml, I believe developers and designers alike will be fooled into trying to generate a number of more complex animations with paths, triggers/timelines, etc. rather than implement new animations via code.  [Karsten Januszewski](http://blogs.msdn.com/karstenj/default.aspx), who we were lucky enough to meet last week, pointed this exact scenario out while I was attempting to mimic the [North Face kiosk carousel](http://www.microsoft.com/casestudies/casestudy.aspx?casestudyid=201147) via a path.  He referenced a [previous post](http://blogs.msdn.com/karstenj/archive/2007/02/23/inspired-by-flash-math-creativity-2-wpf-planets.aspx) of his which shows how to create a custom animation.  Until I grasp the animation framework in WPF, I'll not risk embarrassing myself by attempting to better explain what Karsten already does much better than I.
