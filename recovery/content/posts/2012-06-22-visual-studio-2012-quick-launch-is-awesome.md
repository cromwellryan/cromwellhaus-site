Those who know have coded with me have felt the soul crushing comments whenever they touch a mouse.  It. Must. Die.  For coders at least.  Visual Studio hasn’t always made that easy.  Visual Studio 2012 is here to help with the new Quick Launch feature. ([VsVim](https://login.live.com/login.srf?wa=wsignin1.0&wtrealm=visualstudiogallery.msdn.microsoft.com&wreply=https%3a%2f%2fvisualstudiogallery.msdn.microsoft.com%2f59ca71b3-a4a3-46ca-8fe1-0e90e3f79329%3fstoAI%3d10&wp=MBI_FED_SSL&wlcxt=microsoft%24microsoft%24microsoft) will help too, but in due time).

Quick Launch is found in what used to be the window chrome.

[![image](/images/wp-content/uploads/2012/06/image_thumb.png "image")](http://cromwellhaus.com/wp-content/uploads/2012/06/image.png)

Stop that!  Don’t go mousing up there just yet.  It quite blaringly asks you to hit CTRL+Q.  Just do it.  Now type ‘Keyboard’

Holy frick!  It took us into a section of the Tools –> Options dialog.  That’s a deep link if ever one existed.[![image](/images/wp-content/uploads/2012/06/image_thumb1.png "image")](http://cromwellhaus.com/wp-content/uploads/2012/06/image1.png)

**Open to all comers**

What if we search for ‘gist’?

[![image](/images/wp-content/uploads/2012/06/image_thumb2.png "image")](http://cromwellhaus.com/wp-content/uploads/2012/06/image2.png)

Yeah, that’s my [Gister](visualstudiogallery.msdn.microsoft.com/b31916b0-c026-4c27-9d6b-ba831093f6b2) VS Extension.  I didn’t have to do anything to play in the sandbox.  Resharper refactorings, TestDriven.Net, and Telerik’s tools all show up side-by-side commands like the new backed in Continuous Test Runner.

[![image](/images/wp-content/uploads/2012/06/image_thumb3.png "image")](http://cromwellhaus.com/wp-content/uploads/2012/06/image3.png)

**Make your own keyboard combos**

Also notice that the respective keyboard combos are called out clearly.  If you find yourself using Quick Launch often for the same command, setup a specific shortcut.

[![image](/images/wp-content/uploads/2012/06/image_thumb4.png "image")](http://cromwellhaus.com/wp-content/uploads/2012/06/image4.png)

Note that Quick Launch is context sensitive.  Commands that are not available (i.e. Resharper Rename refactoring in a non-code file) will not appear in the search.
