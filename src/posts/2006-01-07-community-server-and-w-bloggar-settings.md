This is really just for my future reference, but since I had a hard time finding out here are the settings I used for [w.Bloggar](http://bloggar.com/ "w.Bloggar") and [Community Server 2.0](http://communityserver.org/ "Community Server")
  
  
**API Section**

- **Blog Tool/API:** (Custom)
- **Account Alias:** Ryan @ CromwellHaus.com
- **Ping:** Weblogs.com
- **API Server:** www.cromwellhaus.com
- **Path:** /cs/blogs/ryanc/MetaBlog.ashx

**Custom Section**

- **Posts::** metaWeblog API
- **Categories:** metaWeblog API - Single
- **Templates:** Blogger API
- Defaults for everything else

I found the starter for these on the [CS MetaBlog API Thread](http://communityserver.org/forums/480628/ShowThread.aspx#480628)
